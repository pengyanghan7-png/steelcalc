# SteelCalc 钢板重量计算

面向工厂的简体中文订单工作台。V2.0 在原有钢板算重和生产订单 Excel 的基础上，加入发货、到账及经营统计。

[打开 GitHub Pages 网页](https://pengyanghan7-png.github.io/steelcalc/)

## 订单管理

1. 在「项目信息」导入历史订单 Excel，即可按名称搜索客户、使用历史表面处理和价格建议。导入会替换上一份历史目录，本地手动新增的客户与本地订单照常保留。
2. 录入零件类型、订单数量和表面处理。标准矩形板填写一组长、宽、厚。折弯板及特殊件可按「添加组成板」录入每组板材尺寸、每件用量和贯穿孔，或使用人工单件净重。折弯板的尺寸按图纸确认的展开尺寸或分段计重尺寸录入。
3. 选择计价方式后，可以使用该客户、表面处理和单位组合的最近三条单价，也可以自行输入。历史单价缺少可识别的单位或日期时不用于建议，未来日期不计入已使用价格。
4. 生成结果后，查看生产订单表与逐行计算明细，导出包含这两个工作表的 Excel。多块板组成的成品在生产订单表占一行，计算明细中列出各组成板。
5. 在「本地项目」里新建订单或切换到已保存的订单。导入数据和项目均保存在当前浏览器，清除站点数据会删除本地记录。

钢材密度固定为 7.85 g/cm³。净体积为原板体积减去所有贯穿孔体积，单件净重（kg）为净体积（mm³）乘以 7.85 再除以 1,000,000。理论总净重为单件净重乘以订单数量。结果及 Excel 分别显示两位体积小数和三位重量小数，合计按未舍入数值计算。录入人员需对照图纸核查孔位、重叠和实际加工条件。

## 员工工作台

1. 在生产订单表点击「转入发货」，确认客户、付款约定及每个型号的结算单价。交接记录保存当时的订单数据，理论重量继续用于报价参考。
2. 可登记加工进度、补传图纸和分批创建送货单。按件使用实际件数，按实重使用该型号的实称公斤数。每个型号的送货金额四舍五入至分。差异单经处理确认后进入结算。
3. 现款及货到付款直接按确认后的送货单结算。月结按客户和送货月选择送货单，并填写双方约定的付款截止日。到账登记和流水核实分开，尾差保留原应收、减免原因及金额。
4. 「统计与导出」可按客户、订单和期间查看经营指标，导出汇总、订单、送货、结算与到账明细。跨订单月结单的回款按客户范围统计。

员工工作台的数据与附件保存在当前浏览器的 IndexedDB。此版本用于单机流程试用，正式多人共享与岗位权限需要接入后台。

## 本地开发

需要 Node.js 24 和 npm。

```sh
npm ci
npm run dev
npm test
npm run check
```

## GitHub Pages 发布

`main` 保存源码，`gh-pages` 根目录保存构建产物及空的 `.nojekyll` 文件。发布更新时，将 `PAGES_BASE_PATH` 设为 `/steelcalc` 后执行 `npm run build`，将 `out/` 内的文件同步到 `gh-pages` 根目录，保留 `.nojekyll`，提交并推送。
